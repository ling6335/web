# 稍后读 · 个人阅读清单

一个轻量的个人阅读清单 Web 应用，用来收藏以后想读的文章。使用原生 HTML、CSS 和 JavaScript 构建，无需安装依赖或配置构建工具。

## 本地运行

在项目根目录运行：

```bash
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。

## 功能

- 添加文章标题、链接和个人笔记
- 在浏览器本地保存阅读清单，关闭页面后仍可访问
- 搜索标题、笔记和链接，并按待阅读或已读状态筛选
- 标记阅读状态、删除条目
- 响应式布局，支持 `⌘ K` / `Ctrl K` 聚焦搜索和 `Esc` 清空搜索

清单数据保存在当前浏览器的 `localStorage` 中，不会同步到其他浏览器或设备。
